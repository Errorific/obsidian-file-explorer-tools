# File Explorer Tools

File Explorer Tools extends Obsidian's built-in file explorer with controls for hiding, sorting, and navigating files and folders.

The plugin is under development and is not ready for general use.

## Development

Requirements:

- Node.js 20.19 or later
- npm

Install dependencies:

```sh
npm install
```

Run the development build:

```sh
npm run dev
```

Run the automated checks:

```sh
npm test
npm run lint
npm run build
```
